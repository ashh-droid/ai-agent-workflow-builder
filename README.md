# AI Agent Workflow Builder

A secure, multi-tenant workflow engine built with Nhost, Hasura, PostgreSQL, GraphQL, Nhost Functions, Gemini, and Next.js.

This repository is the implementation for the full-stack assignment described in `docs/ASSIGNMENT.md`. The project is designed around the required end-to-end demo: two organizations, organization-scoped permissions, step-level permission gates, manual + automated triggers, live `step_runs` subscriptions, quota enforcement, retry handling, and approval-gate pause/resume.

> Active implementation is being developed in a dedicated branch and will be merged after validation.
